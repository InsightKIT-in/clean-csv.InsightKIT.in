# clean-csv.InsightKIT.in

> Clean CSV — an email and phone list cleaner built by InsightKIT for GMBInsight exports.

## Overview

clean-csv.InsightKIT.in transforms messy CSV files into clean, deduplicated contact lists in seconds.

Simply upload the CSV generated by GMBInsight, and the tool automatically extracts valid email addresses and phone numbers, removes duplicates, and presents them in an easy-to-copy format.

## Features

- 📂 Drag & drop CSV upload
- 📧 Automatically extract valid email addresses
- 📞 Automatically extract phone numbers
- ✅ Remove duplicate entries instantly
- 📊 Display rows scanned and valid results
- 📋 One-click copy for emails or phone numbers
- ⚡ Instant processing with no waiting
- 💻 Runs entirely in your browser
- 🔒 No backend, no login, and no installation required

## How It Works

1. Export your business data as a CSV from GMBInsight
2. Drop the CSV file into the website
3. The tool scans every row automatically
4. Valid emails and phone numbers are extracted
5. Duplicate entries are removed
6. Copy the cleaned lists and use them for outreach, CRM imports, or analysis

## Why It Exists

CSV exports often contain duplicate contacts, empty values, and unnecessary data that make outreach difficult.

Clean CSV isolates the information that matters—emails and phone numbers—while automatically cleaning and deduplicating the dataset, saving time and reducing manual work.

## Tech Concept

- CSV parsing
- Email extraction and validation
- Phone number extraction
- Automatic deduplication
- Real-time statistics
- Client-side processing with zero data upload
